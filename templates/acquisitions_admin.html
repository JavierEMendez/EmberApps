Parcel cache

Parcel cache (speeds up searches)

Pre-loads StratMap parcels for Houston-metro counties into a local DB so searches don't hit the live ArcGIS API every time. HCAD/MCAD overlays still run live for owner-name freshness. Counties are re-checked weekly but only re-downloaded when StratMap actually publishes a change, so a check is normally free. A load that is interrupted resumes where it stopped rather than starting over.
